# EcoMovement

## Sobre o projeto

A **EcoMovement** é uma plataforma desenvolvida para o Challenge FIAP 2026 em parceria com a SoulUp.  
O objetivo do projeto é incentivar hábitos sustentáveis por meio da tecnologia, permitindo que usuários realizem ações conscientes, acumulem pontos e convertam esses pontos em benefícios reais.

A solução busca aproximar o ambiente digital de impactos positivos no mundo físico, promovendo práticas como o uso de transporte público, participação em ações sustentáveis, missões educativas e doações para ONGs parceiras.

---

## Objetivo do Front-End

O objetivo desta etapa é desenvolver uma interface web completa, responsiva e visualmente organizada para apresentar a proposta da EcoMovement.

O site foi construído com foco em:

- Estrutura semântica em HTML;
- Identidade visual consistente;
- Navegação simples entre páginas;
- Organização clara dos conteúdos;
- Responsividade para diferentes tamanhos de tela;
- Apresentação da equipe e da proposta do projeto.

---

## Páginas desenvolvidas

O projeto conta com as seguintes páginas:

- **Index**: página inicial de entrada do projeto;
- **Início**: apresentação principal da plataforma;
- **Quem Somos**: apresentação dos integrantes da equipe;
- **Sobre**: explicação do projeto, solução e funcionalidades;
- **FAQ**: perguntas frequentes sobre a plataforma;
- **Contato**: formulário visual para contato com a equipe.
